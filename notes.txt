Password Hash: A password hash is a one-way mathematical transformation of a plaintext password 
into a fixed-length string of jumbled characters
 If a server gets hacked, attackers only see random hash strings instead of plain text passwords.
 In hashing for same text we always get the same jumbled string.
 cannot convert the hash back to plain text
